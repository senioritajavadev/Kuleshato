# Проверка результата

Используй навык, когда пользователь просит проверить изменение или запустить тесты.

1. Определи изменённые Java-файлы, инструкции проекта и доступные команды Maven или Gradle.
2. Выбери минимальную проверку, которая покрывает изменение; не предполагай, что типовая команда подходит проекту.
3. До каждой команды покажи точную команду и запроси подтверждение. Это обязательно и для тестов, и для сборки. Без терминала для подтверждения команду не запускай.
4. Разбери код завершения, ошибки и предупреждения. Отличай успешный запуск от частичной или не выполненной проверки.
5. В итогах перечисли фактически запущенные команды и их результаты.

Не устанавливай зависимости и не меняй конфигурацию ради проверки без отдельного согласия.
