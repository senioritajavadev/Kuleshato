# Ревью изменений

1. Ограничь ревью изменёнными или названными пользователем Java-файлами.
2. Проверь логику, крайние случаи, безопасность, обработку ошибок, дублирование и тесты. Не выдавай предположения за дефекты.
3. Сначала сообщи существенные находки с серьёзностью, путями и строками. Если дефектов нет, уточни область просмотра.
4. Изменяй код только по просьбе. Запускай команды только после отдельного подтверждения; записи файлов проходят стандартный показ diff и подтверждение.
